## 一、Arc Institute（当前最激进）

- **2025-02-25** 发布 Arc Virtual Cell Atlas，首版整合 3 亿+ 细胞：Tahoe-100M（1 亿细胞、6 万药物-细胞互作、50 个癌细胞系、1,200 种药物）＋ scBaseCount（2 亿细胞、21 个物种，由 AI agent 自动策展重处理）。https://arcinstitute.org/news/arc-virtual-cell-atlas-launch ；https://arcinstitute.org/news/arc-vevo
- **2025-06-23** 发布第一代虚拟细胞模型 State：约 1.7 亿观测细胞＋1 亿+ 扰动细胞训练；在 Tahoe-100M 上扰动效应区分度提升 50%、差异表达基因识别准确率翻倍；同期公开评测框架 Cell_Eval。https://arcinstitute.org/news/virtual-cell-model-state
- State 预印本 **2025-06-27**（bioRxiv 10.1101/2025.06.26.661135），正式版 **2026-08-31** 发表于 Cell（DOI 10.1016/j.cell.2026.07.052），摘要称在大数据集上效应区分度提升“超过 30%”。https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=%22predicting%20cellular%20responses%20to%20perturbation%22
- **2026-01-09** 新模型 Stack 预印本（bioRxiv 10.64898/2026.01.09.698608）：对未标注细胞做 in-context learning，无需按数据微调即可预测化学扰动/供体差异的效应；已列入 Arc 工具页。https://arcinstitute.org/tools/stack
- **2026-02-24** 入选 The Audacious Project 2025 批次，专项支持 Virtual Cell Initiative，计划开展“10 亿级细胞实验”，并与 Tahoe、Biohub、10x Genomics、Ultima 合作。https://arcinstitute.org/news/the-audacious-project-2025
- 后续管线：**2026-10-20** Bolero（细胞状态条件化的调控序列模型）、**2026-10-05** PIE、**2026-10-15** 2026 Virtual Cell Challenge 招募。https://arcinstitute.org/news
- 融资：未找到 Arc 自身股权融资的一手公告（其为非营利研究所，资金以慈善捐赠为主）。

- 采用案例以“模型→湿实验验证”为主：Google C2S-Scale（2025-10）、Genentech SCimilarity 命中 3D 水凝胶体系、Recursion Phenom 对外授权托管；尚无公开的“虚拟细胞模型直接支撑 FDA 申报”案例。

## 产业格局判断（5 条）

1. **数据而非架构是护城河**。Arc 用 3 亿细胞+1 亿扰动细胞把 State 推到 Cell，CZI 用 1.12 亿细胞做跨物种，头部机构都在自建“扰动数据工厂”；模型能力差异越来越由数据规模与因果性（CRISPR 扰动）决定。
2. **两极格局：非营利平台 vs 大厂算力**。Arc/CZI 提供开放模型与基准（Cell_Eval、cz-benchmarks），NVIDIA 提供算力与分发（BioNeMo），三方在 2025-10 形成事实上的“开放虚拟细胞联盟”，创业公司与药企更多是使用者。
3. **药企仍在“评估期”，未进入“依赖期”**。除 Genentech（SCimilarity/BRAID）与 Recursion（Phenom）外，AZ、Novartis、Pfizer 等未见一手公开成果；模型目前主要替代早期筛选，而非决策链。
4. **评测正成为话语权抓手**。Cell_Eval、cz-benchmarks、VCBench 在 18 个月内密集出现，谁定义 benchmark，谁就定义“什么是好模型”，这比再训一个模型更具产业杠杆。
5. **监管尚未为“虚拟细胞”单独立规**。FDA 只给通用 AI 可信度框架（2025-01），EMA 文本未能核实；短期商业化仍靠“模型提假设＋湿实验验证”的混合证据链，纯 in silico 证据难入申报。
