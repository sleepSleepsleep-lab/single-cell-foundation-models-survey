# 专题：scRNA-seq 连续值的表示与离散化

> 面向 scBERT / scGPT / Geneformer 一类 Transformer 基础模型的输入表示问题
> 信息截至 **2026-10-24**；标注【证据】= 论文/基准中的实测结论，标注【建议】= 本文的推断或可执行方案，尚未见公开发表。

---

## 摘要：五条判断

1. **Transformer 并不排斥连续值**。它排斥的是"把标量当 token id 去查表"。连续标量完全可以用加性嵌入注入（`h = E_gene[g] + MLP(x)`），这在表格 Transformer、时间序列、连续扩散里是标准做法。所以"必须离散化"是**为了复用 MLM/CLM 的交叉熵目标与词表接口**（尤其要与 LLM 词表融合），不是架构硬约束。
2. **硬分箱确有损，但"离散化"本身不是原罪**。2026 年最大规模的对照实验（1000 万细胞 / 100 个数据集 / 26 个测试组织）显示：**soft binning > 连续编码 ≈ log 分箱 > 硬分箱**；硬分箱在所有指标上一致掉点【证据】。
3. **可能被高估的变量是 gene encoding，不是 value encoding**。同一实验里，可学习基因嵌入 vs ESM-2 蛋白嵌入的差距（macro-F1 0.860 vs 0.547）远大于四种值编码之间的差距【证据】。做消融时必须固定基因侧，否则结论不可信。
4. **tokenizer 的威力在分布偏移下才显现**。HEIMDALL 的模块化拆解显示：同分布评测时换 tokenizer 几乎没差别；跨组织、跨物种、跨基因 panel、逆扰动预测时，tokenizer 成为决定性因素，且"混合 tokenizer"能超过任一现有方案【证据】。
5. **最值得抄的不是某个模型，而是四个"信息保全"原语**：保序软编码（PLE）、残差/多级量化（RVQ）、可学习边界（FSQ / Lloyd-Max）、以及"离散 token + 连续标量"双通道。这四件事在表格学习、音频编码、图像生成、时间序列里都已被反复验证，迁到 scRNA 的改造成本很低。

---

## 0. 先纠正两个前提

**（1）不是"词袋法"。** 词袋（bag-of-words）是把文档表示为词频向量、丢掉词序；scRNA 里的 BoW 类比是"基因出现/计数"的稀疏向量。scBERT/scGPT 做的是 **per-gene value binning + embedding lookup**：每个基因的表达值先量化成 bin 编号，再用编号查一张嵌入表。它丢的是**幅值**，不是顺序。两者损失的信息类型不同，改进手段也不同——这一点值得在写作时区分清楚。

**（2）分箱不省序列长度。** 序列长度由"每个细胞选多少个基因"决定（top-k / HVG / 全基因），跟 bin 数无关。把 50 个 bin 加到 256 个，注意力复杂度不变，变的只是嵌入表大小（K×d）和监督稀疏度。所以"分箱是为了压缩序列"这个常见动机是不成立的；分箱真正的收益是**把回归问题变成分类问题**（可用交叉熵、可与 LLM 词表对齐、量化本身带正则化效果）。

## 1. 硬分箱到底丢了什么：五个可分离的损失

设表达值 x 经标量量化器 Q 映射到重建值 c_k：

```
Q(x) = c_k,  当 x ∈ (b_{k-1}, b_k]
```

**(a) 幅值损失（within-bin）**
```
D = Σ_k ∫_{b_{k-1}}^{b_k} (x - c_k)² p(x) dx
```
同一个 bin 里的所有值被折叠成一个点。等宽分箱与等频分箱都**不是** MSE 最优；MSE 最优的是 Lloyd-Max 量化器（一维 k-means）：边界取相邻重建值的中点，重建值取 bin 内条件均值。也就是说，**只用换边界就能免费降低一部分失真**，不需要改模型结构。

**(b) 序损失**
bin 编号被当作无序类别塞进嵌入表。模型必须从数据里自己学出"5 > 4 > 3"。bin 数少、数据少、或长尾 bin 样本稀疏时，这个序关系学不好，而它恰恰是表达量最重要的语义之一。

**(c) 有效码率远低于名义码率**
50 个 bin 名义上是 log₂50 ≈ 5.6 bit。但 scRNA 是零膨胀 + 长尾：per-cell 归一化 + log1p 之后，绝大多数概率质量挤在最低的几个 bin 里，高表达区间的 bin 几乎是空的。**有效 bit 数远小于 5.6**。这就是"信息损失"最直观的量化解释，也说明"把 bin 加到 256"未必有用——多出来的 bin 可能没有样本。

**(d) 边界不可学习、不可迁移**
边界通常由训练集的全局统计（分位数/最大值）定死。换平台、换测序深度、换物种，分布漂移，边界就失配；而 per-cell 归一化又让"绝对水平"本身不可比。于是同一个 bin 编号在不同数据集里含义不同——这是隐性的分布偏移源。

**(e) 目标错配**
预训练用交叉熵预测 bin，下游却要连续值、log fold-change、DE 基因排序。从 bin 反解只能取 bin 中心，系统性有偏；而 DE 分析恰恰对高表达端的精度最敏感。

## 2. 领域内 2022–2026：六条路线

| 路线 | 代表工作 | 值编码方式 | 关键点 |
|---|---|---|---|
| ① 硬分箱 | scBERT (2022)、scGPT (2024)、GeneCompass | log 归一化后等宽/等距分箱；scGPT 为 **50 个等距 bin**，且最低 bin 专门留给 0 | 简单、可直接复用 BERT；但实测一致劣于软编码 |
| ② 秩编码 | Geneformer (2023)、Cell2Sentence (2024)、scDiVa 的序列化 | 每细胞归一化后按表达量排序，token = 基因身份 + 秩 | 去量纲、抗深度差异；丢绝对幅值，且对 dropout 敏感（丢一个计数，整条秩次平移） |
| ③ 软分箱 | TranscriptFormer (2025)、scFoundation 一类、2026 基准的最佳配置 | 对 bin 做 softmax 软查表：`e = Σ_k w_k(x) · T_k` | 可微、保序、保留 bin 间不确定性；目前实测最优 |
| ④ 连续投影 | CellPLM (ICLR 2024)、UCE (2023/26)、scDiVa 的 `MLP_val(v)`、Heimdall 的连续 `F_E` | 标量直接过 MLP / 线性层，无量化 | 信息保留最完整；但与 LLM 词表不兼容，生成需要额外解码头 |
| ⑤ 学习式量化 | CellTok (2025)、RVQ-Alpha (2026)、2026 单细胞 scaling 工作 | VQ-VAE / 残差 VQ 把**整个细胞**压成 10–34 个码本 token | 面向"细胞级 token"，服务生成与 LLM 融合；不适合基因级 mask 与 DE |
| ⑥ 混合/双目标 | scDiVa (2026)、2026 基准的 soft binning + 标量头 | `h = Emb_gene(g) + MLP_val(v)`，损失 = CE(身份) + λ·MSE(值) | 目前最稳的折中：离散接口保留，幅值信息用回归头补回来 |

### 2.1 证据细节

**2026 大规模对照实验（最直接回答你的问题）**
Sadalski 在 1000 万细胞、100 个数据集上从头训练 8 种配置，系统比较四种值编码（hard binning / log binning / soft binning / raw 连续 MLP）× 两种基因编码（可学习 / ESM-2），在 26 个组织数据集上评测【证据】：

- 最佳配置 = **可学习基因嵌入 + soft binning**，macro-F1 **0.860 ± 0.089**；
- 最差配置 = ESM-2 + log binning，macro-F1 **0.547 ± 0.152**；
- **hard binning 在所有指标上一致变差**；
- 结论原话：基因编码的影响大于表达值编码。

**HEIMDALL（tokenizer 的模块化拆解）**
把 tokenizer 分解为 `F_G`（基因身份）、`F_E`（表达值）、`F_C`（顺序/选基因/聚合）三个模块，复现了 scGPT、Geneformer、scFoundation、scBERT、UCE 五家的 tokenizer【证据】：

- 训练/测试同分布时，tokenizer 选择"几乎没有影响"；
- 跨组织、跨物种、跨基因 panel、逆扰动预测时，tokenizer 成为决定性因素；
- 不同模型的模块可以拆开重组，**混合 tokenizer 能超过任一原版**；
- 作者结论："通用可迁移性仍依赖一个非通用的 tokenizer 接口。"

**分箱 vs 秩编码的噪声鲁棒性**
Atti & Subramaniam (2025) 在 Myeloid/hPancreas 上给 20% 细胞加高斯噪声【证据】：

- 分箱模型（scGPT、SCMAMBA-2）准确率掉 **11%**，秩编码（Geneformer）掉 **8%**；
- scGPT 的预测分布偏向训练集中的多数类（CD14 过预测 +16%），Geneformer 的 macro-F1 高出 **26%**；
- 但两者都输给 Seurat v5 统计基线（Geneformer 落后 9%）——提示"换 tokenizer"不能解决全部问题。

**scDiVa（2026）：秩不够，值要单独回归**
`h = Emb_gene(g) + MLP_val(v)`，双向 Transformer + 掩码离散扩散，损失 = 身份交叉熵 + 数值 MSE 双目标；去掉绝对位置编码、用熵归一化排序替代纯表达量排序【证据】。在 rank-value 联合重建上 Spearman 显著优于 Geneformer/GeneMamba，说明**"只保留秩"会丢幅值，"只保留 bin"会丢精度，双目标才补得回来**。

**细胞级量化：VQ 与 RVQ**
- CellTok：VQ-VAE 把每个细胞压成 **32 个码**（码本 256、每码 8 维），早期融合进 Qwen2.5-7B 词表，6800 万细胞训练【证据】；
- RVQ-Alpha：**8 个残差码本 × 32 项**，每细胞 **10 个 token**，比 CellTok 少 3.4×；实证显示前几个码本编码"谱系级"身份，后几个码本编码"谱系内功能状态"——即**残差量化自动形成粗→细的层级**【证据】；
- 2026 年的单细胞 scaling 工作用"学习式量化 VAE tokenizer + 因果 Transformer"，拟合出双指数 scaling law，说明学习式 tokenizer 不阻碍规模化【证据】。

## 3. 三条反直觉结论

1. **"离散化导致信息损失"这个诊断对，但"所以要去掉离散化"这个处方不一定对。** 去掉离散化会同时去掉：交叉熵目标、词表共享、与 LLM 对齐的能力、量化带来的正则化。soft binning 的本质是"保留离散接口 + 把硬指派换成软指派"，代价最小、收益最直接。
2. **同分布 benchmark 无法区分 tokenizer 好坏。** 必须用跨组织/跨物种/跨 panel/扰动这种分布偏移场景来测，否则结论会被"过拟合到评测集"污染。
3. **基因侧的选择可能比值侧更重要。** 如果你的目标是改进 value encoding，实验里一定要把 gene embedding 固定住（或至少做 2×4 全交叉），否则 0.860 vs 0.547 这种量级的差距会把值编码的效应完全淹没。

## 4. 跨领域可迁移清单

按"改动成本 / 预期收益"排序。每条给：原理 → 在 scRNA 的落点 → 代价。

### A 组：只改 value encoder，几乎零成本

| 方法 | 来源领域 | 做法 | 代价 / 风险 |
|---|---|---|---|
| **A1 线性插值分箱（PLE）** | 表格深度学习（Gorishniy et al., NeurIPS 2022） | 值落在 bin k 与 k+1 之间时，`e = (1-w)·E_k + w·E_{k+1}`，`w = (x-b_k)/Δ`。保序、保幅值、可微，嵌入表大小不变 | 改动约 10 行；bin 数不变，不增加参数 |
| **A2 序数/单调嵌入** | 序数回归（CORAL, Cao et al. 2020） | 强制 `E_k = E_0 + k·Δ`，或对 bin 嵌入加单调正则；输出侧用累积 logits 而非独立 softmax | 可能限制表达力；建议先做正则而非硬约束 |
| **A3 周期/傅里叶特征** | NeRF / 表格 DL（Tancik 2020；Gorishniy 2022 periodic） | `[sin(2πf_j x), cos(2πf_j x)]` 多频拼接，与 bin 嵌入相加 | 频率需调；对高表达端的细微差异敏感 |
| **A4 科学计数法 token（xVal）** | 科学 LLM（Golkar et al. 2023） | 尾数 token + 指数 token + 符号，嵌入相加；跨数量级外推好 | 每值 2–3 个 token；实现略繁 |

**推荐先做 A1。** 它是"分箱"与"连续"之间的连续谱：w=0 时退化为硬分箱，w=0.5 时是两个 bin 的平均；不增加词表、不改变序列长度，却能同时保住序与幅值。

### B 组：多级/残差量化，加 token

| 方法 | 来源领域 | 做法 | 代价 / 风险 |
|---|---|---|---|
| **B1 残差量化（RVQ/RQ）** | 音频编码（SoundStream/EnCodec）、图像生成（RQ-VAE, CVPR 2022） | 第一级量化 `c1=Q1(z)`，第二级量化残差 `c2=Q2(z-c1)`，`ẑ=c1+c2`；每级一个 token | 序列 ×2–3；需两级码本；但天然支持"粗 token 做 CE、残差做 MSE" |
| **B2 比特平面 token（Analog Bits）** | 扩散生成（Chen et al. 2022） | 值量化到 8–16 bit，按位切成 token；精度可控、天然有序 | 序列 ×8–16，需权衡；适合"少基因、高精度"场景 |
| **B3 FSQ（有限标量量化）** | 图像生成（Mentzer et al. 2023） | 每维 `u=tanh(Wx+b)`，`q=round(u·L/2)`，STE 反传；无码本、无坍缩 | 每基因 L 级（如 8/16）；边界可学习 |
| **B4 LFQ（无码本量化）** | 视频生成（MAGVIT-v2, 2023） | 无显式码本，二值化 + 熵惩罚防坍缩 | 更适合大规模词表；实现需调 |

### C 组：自适应码率与最优量化，改边界/预算

| 方法 | 来源领域 | 做法 | 代价 / 风险 |
|---|---|---|---|
| **C1 Lloyd-Max / 一维 k-means** | 量化理论（Lloyd 1982; Max 1960） | 按每个基因的分布迭代求 MSE 最优边界与重建值，替换等宽/等频 | 离线统计一次；per-gene 边界表需存储 |
| **C2 按基因分配 bin 数（bit allocation）** | 音频/图像压缩（MP3、JPEG 按频带分配比特） | `K_g ∝ 表达熵 / 方差 / 检出率`；高信息基因多 bin，低信息基因少 bin | 词表变成变长；实现需 per-gene 偏移索引 |
| **C3 μ-law / A-law 压扩** | 电话语音（G.711） | 先 `y = sign(x)·ln(1+μ|x|)/ln(1+μ)` 再均匀量化；μ 可调，匹配长尾 | 与 log1p 类似但更可控；需调 μ |
| **C4 KL 校准边界** | 神经网络量化（TensorRT entropy calibration） | 选边界使量化前后分布 KL 最小，而非 MSE 最小 | 更贴合"下游判别"目标；实现简单 |
| **C5 率失真视角选 K** | 信息论 | 把 bin 数当码率，画 D(R) 曲线；用验证集失真拐点定 K | 避免"bin 越多越好"的盲目性 |

**C2 是本文认为最被忽视、也最有论文价值的一条【建议】**：现有工作几乎都用"全体基因同一个 K"，但基因的表达熵差异极大（管家基因 vs 稀有转录因子）。按熵分配码率，等价于在固定词表预算下最大化互信息 `I(X; Q(X))`，与 MP3/JPEG 的比特分配是同一套数学。可以做成"变长码本 + per-gene offset"，也可以更简单地做成"三档 K（8/32/128）按熵分组"。

### D 组：换生成范式或训练目标

| 方法 | 来源领域 | 做法 | 代价 / 风险 |
|---|---|---|---|
| **D1 离散扩散 / 任意阶 AR** | D3PM、MaskGIT、LLaDA | 用吸收态 [MASK] 做前向腐蚀，双向去噪；与值编码正交 | 已由 scDiVa 验证；训练成本中等 |
| **D2 连续扩散 / flow matching** | 图像/分子生成 | 完全绕开离散 token | 失去 LLM 词表接口；与"复用 LLM"的目标冲突 |
| **D3 分布头（discretized mixture）** | PixelCNN++ 的 discretized logistic mixture；scRNA 的 NB/ZINB 似然 | 输出 256 级上的混合分布参数，而非单个 bin 的 one-hot | 头稍复杂；但能同时给出均值与不确定性 |
| **D4 细胞级 tokenizer** | VQ-VAE / RVQ + LLM early fusion | 整个细胞 → 10–34 个码，进 LLM 词表 | 不适合基因级 mask/DE；适合生成与群体级任务 |

### E 组：几个便宜的训练技巧【建议】

- **抖动量化（dithering）**：训练时在 bin 边界上加小幅随机扰动（音频量化的标准做法），迫使模型对边界不敏感，等价于正则化。
- **量化感知训练（QAT）**：前向用离散 bin，反向用 STE 或直通软编码；推理时再切回连续通道，避免量化误差进入下游。
- **软目标**：把 one-hot bin 换成以真值为中心的三点核（`[0.1, 0.8, 0.1]`），本质是软分箱的输出侧版本。
- **一致性正则**：对同一细胞做两种不同 bin 粒度，要求表示一致——把"量化误差"当噪声做数据增强，而不是试图消除它。
- **BPE over values**：对量化后的值序列做 BPE，把常共现的相邻 bin 合并成"值短语"，数据驱动地决定粒度（这条更偏脑洞，未见单细胞工作）。

## 5. 落点图：模型里到底该换哪个部件

| 部件 | 现状（scBERT/scGPT 类） | 可替换为 |
|---|---|---|
| 值编码 | bin id → `Embedding[K]` | PLE / MLP / FSQ / 双层 RVQ |
| 词表组织 | `gene token + value token` 相加，或 `(gene,bin)` 组合 token | 保持解耦（避免 G×K 词表爆炸） |
| 预训练目标 | masked bin 交叉熵 | CE + λ·MSE 辅助 / 分布头 / 双目标 |
| 序列构造 | 按表达量 top-k、按秩排序 | 熵归一化排序（scDiVa）/ 可学习选择 |
| 位置编码 | 绝对位置（把基因顺序当序列） | 去掉绝对位置 + RoPE/相对位置（scDiVa） |
| 细胞聚合 | mean-pool | attention pool / [CLS] / VQ token |
| 生成头 | bin softmax | 分布头 / 离散扩散 |

## 6. 一个可直接执行的最小实验方案

**控制变量**：同 backbone、同参数量（对齐嵌入表大小）、同 token 数、同训练步数、同数据划分；gene embedding 固定为可学习（或做 2 组交叉）。

| 编号 | 配置 | 改动量 | 预期 |
|---|---|---|---|
| P0 | 基线：log1p + 50 等宽 bin + 查表 | — | 参照 |
| P1 | P0 换成 PLE 线性插值（K 不变） | ~10 行 | 小幅稳定提升 |
| P2 | P1 + 标量回归辅助头（λ=0.1） | 加一个线性头 | 幅值/DE 指标明显改善 |
| P3 | per-gene Lloyd-Max 边界（离线） | 预处理脚本 | 同等 K 下失真下降 |
| P4 | 两级 RVQ（粗 16 + 细 16） | 中等 | 重建精度提升，序列 ×2 |
| P5 | FSQ（L=8/16，STE，边界可学习） | 中等 | 端到端学边界，可能优于 P3 |
| P6 | 连续 MLP（raw embedding） | 小 | 上界参照（但失去离散接口） |

**评测协议（缺一不可）**：
1. 重建：masked value 的 MSE / Spearman / 分位数误差；
2. 判别（同分布）：cell type 的 macro-F1（避免只看 accuracy，长尾类会被淹没）；
3. 判别（分布偏移）：跨组织、跨物种、跨基因 panel —— 这才是 tokenizer 的试金石；
4. 下游：DE 基因排序（top-k 命中率）、扰动预测（Δ 相关）、批次整合（batch/bio 两个维度）；
5. 消融：K ∈ {5, 10, 50, 100, 256}，报告"有效码率"（每个 bin 的实际样本数分布），而不只是 K。

---

## 7. 陷阱清单

1. **别用"压缩序列"当分箱的理由**——序列长度由基因数决定。
2. **加 bin 数 ≠ 更好**：嵌入表线性增长、长尾 bin 无梯度、有效码率可能不升反降。
3. **基因侧会淹没值侧**：不做 2×4 交叉消融，结论不可信。
4. **归一化/缩放可能比 tokenizer 更重要**：Chronos 在时间序列上的经验是"mean-scaling 比复杂 tokenizer 更关键"；先检查 scale 再谈编码。
5. **同分布提升可能是过拟合**：HEIMDALL 已经证明同分布下 tokenizer 差异很小。
6. **零膨胀要单独处理**：bin 0 同时承担"未检出"和"低表达"两种语义，建议 zero 单独 token 或零膨胀头（ZINB）。
7. **per-cell 归一化 vs 绝对水平**：前者让值不可比，后者被测序深度污染；秩编码对 dropout 敏感，分箱对边界敏感——两者都有偏，别指望单一方案通吃。
8. **别忽视强基线**：线性/PCA/Seurat 仍能打赢不少基础模型（Ahlmann-Eltze et al., Nature Methods 2025），改进 tokenizer 的收益要放在这个背景下评估。
